# Шагомер — Android-приложение

Считает шаги встроенным датчиком телефона (тот же, что использует Google Fit),
отправляет их в Google-таблицу спонсора и начисляет **1 балл за день с 10 000+ шагов**
(максимум 1 балл в день). Спонсор видит в таблице, кому сколько должен, переводит
деньги на карту вручную и отмечает выплату — баланс в приложении участника обновляется.
Языки: русский и узбекский (переключатель в приложении).

## Безопасность — что приложение может, а что нет

Приложение собирается из этого открытого исходного кода. Разрешения, которые оно
запрашивает, перечислены в `app/src/main/AndroidManifest.xml`:

| Разрешение | Зачем |
|---|---|
| Физическая активность (ACTIVITY_RECOGNITION) | читать шаговый датчик |
| Интернет | отправлять число шагов в таблицу спонсора |
| Уведомления | показывать счётчик в шторке и «+1 балл» |
| Фоновая служба, автозапуск после перезагрузки | считать шаги, когда приложение закрыто |

Нет доступа к контактам, СМС, звонкам, фото, файлам, камере, микрофону, местоположению.
Никакой рекламы и сторонних библиотек аналитики. В интернет уходит только: код
участника, его имя и число шагов по дням — и только на тот адрес, который участник
сам ввёл в приложении.

## Получить APK (сборка на GitHub, без Android Studio)

1. Создайте аккаунт на github.com, нажмите **+ → New repository**, имя `shagomer`,
   видимость **Public**, Create repository.
2. Загрузите в него все файлы этой папки (включая скрытую папку `.github`).
   Удобнее всего через GitHub Desktop или командой:
   ```
   git init && git add -A && git commit -m "Shagomer" && git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/shagomer.git && git push -u origin main
   ```
3. Откройте вкладку **Actions** — сборка запустится сама и займёт 5–8 минут.
4. Когда появится зелёная галочка, во вкладке **Releases** будет файл `shagomer.apk`.
   Постоянная ссылка на последнюю версию:
   `https://github.com/ВАШ_ЛОГИН/shagomer/releases/latest/download/shagomer.apk`

Эту ссылку (или сам файл) можно отправить участнику в Telegram.

### Как установить участнику (например, бабушке)

1. Открыть ссылку или файл `shagomer.apk` на телефоне.
2. Телефон спросит «Разрешить установку из этого источника?» → Разрешить.
3. Нажать «Установить». Если появится окно Google Play Protect
   («Неизвестное приложение», «Проверить») → «Установить без проверки» / «Всё равно установить».
   Это стандартное предупреждение для всех приложений не из Play Маркета.
4. Открыть «Шагомер», разрешить «Физическая активность» и «Уведомления».
5. Ввести имя и адрес таблицы спонсора (его даёт спонсор), нажать «Сохранить».
6. На Xiaomi/Huawei/Samsung: Настройки → Батарея → для «Шагомера» выбрать
   «Без ограничений» / «Автозапуск», иначе система может остановить подсчёт.

Новые сборки ставятся поверх старой как обновление, данные сохраняются.

### Сборка в Android Studio (альтернатива)

File → Open → папка `Shagomer` → Build → Build APK(s). Готовый файл:
`app/build/outputs/apk/release/app-release.apk` (подписан тем же ключом).

## Настройка таблицы спонсора (один раз)

Откройте `sponsor/Code.gs` — в начале файла пошаговая инструкция. Итог: ссылка вида
`https://script.google.com/macros/s/…/exec`, которую нужно ввести в приложении
каждого участника вместе с его именем. Одна таблица обслуживает всех участников.

## Как устроен код

- `Store.kt` — хранение шагов по дням, данных участника и сведений о выплатах.
  Датчик `TYPE_STEP_COUNTER` отдаёт накопительное число шагов с момента загрузки
  телефона; приложение записывает только разницу с предыдущим показанием, поэтому
  перезагрузка телефона не приводит к двойному счёту.
- `Sync.kt` — отправка шагов за последние 14 дней в таблицу спонсора (не чаще раза
  в 10 минут, сразу при новом балле и при открытии приложения) и получение назад
  суммы выплат и курса.
- `StepService.kt` — фоновая служба с постоянным уведомлением; при каждом новом
  балле приходит отдельное уведомление.
- `BootReceiver.kt` — перезапускает службу после перезагрузки телефона.
- `MainActivity.kt` — экран с балансом «к выплате», кольцом прогресса, историей дней,
  именем и адресом таблицы, переключателем RU/UZ.
- `app/release.keystore` — ключ подписи. Он хранится в проекте, чтобы любая новая
  сборка ставилась как обновление. Приложение не публикуется в Play Маркете, поэтому
  секретность ключа здесь не критична.

## Ограничения

- Нужен телефон с аппаратным шаговым датчиком (есть почти во всех моделях
  с 2015 года) и Android 8.0 или новее. Для iPhone нужна отдельная версия.
- Защита от накрутки минимальная (лимит 1 балл в день) — рассчитано на семью и знакомых.
